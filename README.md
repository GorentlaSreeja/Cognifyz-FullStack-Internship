# Cognifyz Full Stack Development Internship

This repository contains the 8 tasks completed as part of my Full Stack Development Internship at **Cognifyz Technologies**.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MongoDB
- Mongoose

## Tasks
This repository includes all 8 internship tasks, organized into separate folders.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/GorentlaSreeja/Cognifyz-FullStack-Internship.git
   ```

2. Open the required task folder.

3. Install dependencies:
   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env` file.

5. Run the application:
   ```bash
   npm start
   ```
